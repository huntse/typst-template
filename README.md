# What is this?

This is a template for people to submit tutor-marked assigments for the Open University using
[typst](http://typst.app). It is not in any way endorsed by the university and currently under development so use at your own risk!


## License

MIT, see [LICENSE](LICENSE).

## To use

`typst --compile example.typ` will produce a pdf.

`typst --watch example.typ` will watch `example.typ` and update the pdf on any changes.
